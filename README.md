# 考研专业课复习系统

一个帮助考研同学背专业课的在线工具。导入真题，按章节/错题/随机出题，自评记忆程度，记录错题，按遗忘曲线复习。

## 功能

- 📖 **刷题**：按范围出题（全部 / 指定章节 / 错题本），每道题自评"记得 / 模糊 / 忘记"，看答案后校准"记对 / 记错 / 没理解"，选择错因
- 📕 **错题本**：自动记录错题，按知识点聚合，可手动归档/恢复
- 📊 **总结**：学习统计、自评分布、错因分析、薄弱知识点、章节掌握度
- 🤖 **AI 老师**：
  - **错题诊断**（刷题页顶部）：分析错因、指出薄弱点、精讲知识点、给记忆技巧、推荐相近题
  - **整体分析**（AI 老师页）：根据所有做题记录，分析薄弱章节、薄弱知识点、给学习建议
- ⚙️ **设置**：每轮题数、章节/知识点权重、AI 开关、数据导出备份

## 使用流程

1. 打开链接，进入首页
2. 左侧点「📖 学习」
3. 封面选择范围（全部章节 / 某一章 / 错题本）
4. 点「🚀 开始本轮」
5. 做题 → 自评 → 看答案 → 校准 → 选错因 → 下一题
6. 做完一轮 → 结尾页看统计 → 点「☕ 休息一下」回封面
7. 想看错题 → 左侧「📕 错题本」
8. 想看整体数据 → 左侧「📊 总结」
9. 想听 AI 分析 → 左侧「🤖 AI 老师」

## 学习机制

- **间隔重复（SM-2）**：答对的题间隔会拉长（1天 → 几天 → 几十天），答错的题重新回到 1 天
- **归档**：连续答对 3 次且间隔超过 30 天的题会归档，不再出现在每日复习中
- **错题本**：做错的题自动进入错题本，可以专门刷错题本
- **加权抽题**：优先抽到期的错题、重点知识点、新题

## 数据存储

学习记录保存在云数据库（Supabase），不会丢失。你的错题、复习进度、做题历史都保留。
